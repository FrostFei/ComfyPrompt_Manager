# ComfyUI 提示词整理工具

一个本地 HTML 工具，用来整理 ComfyUI / Stable Diffusion 的正向提示词、负向提示词、常用提示词库、模板库和中英字典。

## 使用方法

1. 直接用浏览器打开 `index.html`。
2. 在中间的正向或负向输入框粘贴完整提示词。
3. 点击「重新分段」，工具会按英文逗号 `,` 和中文逗号 `，` 拆分，并用输入框内容替换当前分段。
4. 点击「增加分段」，工具会保留当前分段，并把输入框内容拆分后追加到末尾。
5. 重新分段和增加分段都会二次确认，防止误操作。
6. 在分段列表中编辑文本、调整权重、删除、上移或下移。
7. 「合并结果」会自动生成逗号分隔提示词，点击「复制」可复制对应提示词。

## 权重规则

- 普通分段导出为：`white hair`
- 权重为 1.0 时不显示权重。
- 权重不为 1.0 时导出为：`(white hair:1.2)`
- 已有权重格式如 `(white hair:1.3)` 会在分段时自动识别。

## 数据保存

- 所有数据保存在浏览器 `LocalStorage` 中。
- 顶部「导出 JSON」可以备份当前全部数据。
- 顶部「导入 JSON」可以恢复之前导出的数据。
- API Key 只保存在本机浏览器的 `LocalStorage`，不会写死在代码里。

## 功能模块

- 正向 / 负向提示词编辑
- 正向 / 负向提示词使用标签页切换显示，当前提示词区占满中间空间
- 提示词分段以多列紧凑网格显示，便于在宽屏上同时浏览更多分段
- 分段编辑、删除、排序
- 共享操作按钮：对当前获得焦点/选中的分段执行权重、排序、入字典和删除
- 权重增加和降低
- 合并导出、一键复制提示词、一键复制整段中文对照
- 常用提示词库：标题、一个或多段提示词、分类、标签、备注
- 提示词库卡片会显示基于字典的中文翻译对照
- 提示词库插入正向/负向时，会追加到对应输入框并自动换行，不直接修改当前分段
- 模板库：名称、正向提示词、负向提示词、标签、备注
- 中英字典：中文、英文、分类、别名、备注
- 字典以紧凑行列表显示，适合保存大量中英对照词条
- 字典词条可追加到正向/负向输入框，不直接分段
- 翻译区：优先查本地字典，未命中时走预留 AI 翻译接口

## DeepSeek 翻译

右侧「AI 设置」支持 DeepSeek：

- Provider 选择 `DeepSeek`
- Endpoint 使用 `https://api.deepseek.com`
- Model 默认使用 `deepseek-v4-flash`
- 点击「输入」填写 API Key
- 点击「测试连接」确认接口可用

API Key 只保存在当前浏览器的 `LocalStorage` 中，不会写死在代码里。

翻译流程：

1. 先查本地字典。
2. 字典未命中时，调用 DeepSeek `/chat/completions`。
3. 每个分段翻译完成后，自动写入字典，形成中英对照表。
4. 同一次或下一次翻译遇到重复分段时，优先从字典复用结果，不再重复调用 AI。
5. 开启「显示 AI 过程」后，会显示字典检查、API 请求、流式返回进度。
6. 开启「DeepSeek 思考模式」后，如果接口返回 `reasoning_content`，会显示在「AI 过程」里。
7. 如果浏览器提示跨域或网络失败，后续需要增加一个本地代理服务来转发请求。

翻译方向支持「自动识别」：

- 纯中文：默认翻译为英文。
- 纯英文：默认翻译为中文。
- 中英混合：默认翻译为英文，适合整理 ComfyUI / Stable Diffusion 提示词。

字典缓存规则：

- 中文 → 英文：保存为 `中文原文 / 英文译文`。
- 英文 → 中文：保存为 `中文译文 / 英文原文`。
- 如果分段已经是目标语言，会直接保留，不调用 AI。
- Mock 翻译不会写入字典，避免污染正式中英对照表。
- 分段列表会读取字典；如果英文分段已有中文对照，会在同一行显示中文翻译。

```js
  // DeepSeek / OpenAI-compatible 翻译请求
}
```
